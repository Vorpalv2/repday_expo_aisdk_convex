# Repday premium features

These documents describe the implemented Free, Plus and Complimentary access, including local caching and cloud-operation trade-offs.

- [Live cross-device sync](./live-cross-device-sync.md): on/off behavior, advantages, limitations and read/write examples.
- [AI Coach](./ai-coach.md): streaming, conversation history, context, storage and usage.

Plus and Complimentary unlock the same features. Plus is subscription-based; Complimentary is manually granted access and requires no recurring payment. A test/live payment mode is an environment setting, not an additional membership tier.
